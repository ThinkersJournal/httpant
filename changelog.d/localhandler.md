kind: `Server::local_route`: handlers that are not `Send` on the actix-web adapter (ROADMAP row 9), conformance case 24
---
`Server::local_route(method, path, factory)` (and `LocalHandlers::route`, `ServeOptions::local_handlers`) registers a handler whose future need not be `Send` and whose state may be an `Rc` or `RefCell`: `factory` runs once on every actix worker thread (two on the cleartext listener, one on the TLS listener) and returns an async function of the `Request`. The actix-web adapter now declares `local_handlers: Yes`; every other adapter refuses a server that has a local route with the new `Error::LocalHandlersNotSupported` before it starts (`require_local_handlers`), and never runs the handler elsewhere.

How: the service stays `Send` and a local route is not a second service. The router holds, for each local route, an ordinary `Send` handler that finds the worker thread's instance in a thread-local and runs its future on that thread's `LocalSet`, so routing (one 404, one 405 with `Allow`) and all five wrappers (body limits, shutdown grace, ACME prefix, `Origin`, HTTPS redirect) are the ones every other route has; none was rewritten, and a local route cannot get round them. A request that is abandoned (body limit, end of the shutdown grace, client gone) aborts the local task, as dropping the future does on the `Send` path. A panic in a local handler is a `500`.

Conformance case 24 (`local-handlers`): an adapter declaring `No` must refuse with the named error; `Yes` must serve a local route with an `Rc` held across an await, route it (404, 405 with `Allow`), refuse a declared 3 MiB body with 413, believe a trusted proxy's forwarded headers for it, answer the ACME prefix before a local route on that very path, redirect a listed host to https and answer 421 for another, and end a local handler that never finishes at the end of the shutdown grace. Five mutants, each serving local routes on actix with one wrapper's setting off, fail it (`local-no-body-limit`, `local-ignores-proxies`, `local-no-challenge`, `local-no-redirect`, `local-no-grace`). The whole suite passes on all six adapters (329 s); `docs/CAPABILITY-MATRIX.md` re-blessed (actix-web: non-`Send` handlers `yes`). Breaking for code that builds the conformance crate's `App` or `Setup` by struct literal (new fields `local`, `challenge`, `https_redirect`). Not published.
